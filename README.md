# Snake Adventure 🐍

基于 **C++17 + SFML 3** 开发的贪吃蛇小游戏，支持五关挑战、智能怪兽 AI、个性化外观设置和中文游戏界面。

这是我学习 C++、数据结构、算法以及 Git/GitHub 过程中开发的个人项目。

## 游戏功能

### 五关挑战
游戏共有五个关卡，随着分数增加，贪吃蛇的移动速度逐渐提升。达到 250 分即可通关。

### 智能怪兽 AI
游戏中存在一只会移动的小怪兽，不同关卡采用不同的行为策略：

- 第 1～2 关：随机巡逻
- 第 3～4 关：随机巡逻与概率追踪
- 第 5 关：使用 BFS 广度优先搜索进行路径规划

当蛇头碰到怪兽时，游戏结束。

### 个性化设置
- 使用色轮自定义背景颜色
- 从本地选择背景图片
- 调整背景图片透明度，并实时预览
- 自定义小蛇颜色
- 三种蛇头造型：小兔子、小熊、小企鹅

### 游戏系统
- 中文主菜单与设置界面
- 分数统计和关卡进度
- 暂停、继续和重新开始
- 撞墙与撞蛇身检测
- 胜利和失败提示

## 游戏操作

| 按键 | 功能 |
|---|---|
| W / ↑ | 向上移动 |
| S / ↓ | 向下移动 |
| A / ← | 向左移动 |
| D / → | 向右移动 |
| Space | 暂停 / 继续 |
| R | 重新开始 |
| Esc | 返回主菜单 |

## 编译与运行

首先安装 CMake、支持 C++17 的编译器以及 SFML 3。

在已正确配置编译环境的情况下，使用以下命令构建项目：

```powershell
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_CXX_COMPILER="C:/msys64/ucrt64/bin/g++.exe" -DCMAKE_MAKE_PROGRAM="C:/msys64/ucrt64/bin/mingw32-make.exe" -DCMAKE_PREFIX_PATH="C:/msys64/ucrt64"
cmake --build build
```

运行游戏：

```powershell
.\build\SFML_First_Project.exe
```

注意：以上路径对应 Windows 上的 MSYS2 UCRT64 环境。如果使用其他编译器或安装位置，需要相应调整。
